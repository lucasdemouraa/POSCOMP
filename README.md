# POSCOMP2025

This repository contains supplementary materials for the study reported in the paper Evaluating the Accuracy and Stability of Frontier LLMs on POSCOMP 2025 Questions.

## POSCOMP 2025 exam
The tables below provide an overview of the answers produced by the LLMs for the multiple-choice questions from the POSCOMP 2025 exam. The questions were supplied to the LLMs as images.

The POSCOMP 2025 data include 50 multiple-choice questions, numbered from 21 to 70. The collection dates are reported in each model-specific subsection.
