These models follow a hierarchical structure based on decision rules derived from data attributes, and each split is guided by purity measures in the nodes. A) When purity is maximum, the node is always split; when it is minimum, it becomes a leaf node.

D) When purity is minimum, the node is not split in order to avoid overfitting; when purity is maximum, the algorithm continues splitting until it reaches maximum depth.  
E) A node with minimum purity represents an ideal state of separation, whereas a node with maximum purity indicates that the model has lost predictive capacity.
